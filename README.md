# Valerio Comella - Portfolio

Portfolio personale e showcase di progetti di **Valerio Comella** (Software Engineer | Unity C#, Mixed Reality & Full Stack Developer).

Sviluppato con [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com) e TypeScript.

## 🚀 Setup & Sviluppo Locale

### Prerequisiti
- [Node.js](https://nodejs.org/) (versione >= 18)
- `npm` o `pnpm`

### Installazione dipendenze
```bash
npm install
```

### Avvio in sviluppo
```bash
npm run dev
```
Il sito sarà accessibile all'indirizzo `http://localhost:4321`.

### Build di produzione
```bash
npm run build
```
Genera la build statica ottimizzata nella cartella `dist/`.
